# Assignment Landing Page

A responsive landing page recreated from the provided Figma design using semantic HTML5 and CSS3.

## Technologies

* HTML5
* CSS3
* Google Fonts (Montserrat)
* CSS Media Queries

## Features

* Responsive desktop, tablet, and mobile layouts
* Layered mountain images
* Irregular shapes using CSS `clip-path`
* Gradient backgrounds and typography
* Responsive mountain cards
* Two-line card descriptions
* BEM-inspired CSS naming
* Semantic HTML structure

## Getting Started

No build tools or dependencies are required.

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in a browser or use VS Code Live Server.

## Implementation

* `style.css` contains base layout and component styles.
* `responsive.css` contains responsive adjustments.
* CSS `clip-path` recreates the angled image shapes.
* `aspect-ratio` and fluid widths are used for responsive images.
* No JavaScript is required for the current static design.
