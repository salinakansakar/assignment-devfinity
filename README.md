# Assignment Landing Page

A responsive landing page implementation based on the provided Figma design.

## Overview

This project recreates the provided landing page using semantic HTML, CSS, and JavaScript.

## Technologies

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS `clip-path`
